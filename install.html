WASSAFRICA sur votre téléphone ou ordinateur

Installez WASSAFRICA comme une application depuis un navigateur compatible. L'installation ne nécessite pas de passer par un magasin d'applications.

Vérification de votre appareil…

Choisissez votre appareil

Android — Chrome, Edge ou navigateur compatible

  1. Ouvrez WASSAFRICA dans Chrome ou Edge.
  2. Ouvrez le menu ⋮.
  3. Choisissez « Installer l'application » ou « Ajouter à l'écran d'accueil ».
  4. Confirmez.

iPhone et iPad — Safari

  1. Ouvrez WASSAFRICA dans Safari.
  2. Appuyez sur le bouton Partager.
  3. Choisissez « Sur l'écran d'accueil ».
  4. Activez « Ouvrir comme app web » si cette option apparaît, puis Ajouter.

Sur iOS/iPadOS, utilisez Safari pour l'installation depuis le navigateur.

Windows — Chrome ou Edge

  1. Ouvrez WASSAFRICA dans Chrome ou Edge.
  2. Cliquez sur l'icône Installer dans la barre d'adresse, si elle apparaît, ou ouvrez le menu.
  3. Choisissez « Installer WASSAFRICA » puis confirmez.

macOS — Chrome, Edge ou Safari

  1. Dans Chrome ou Edge, ouvrez le menu et choisissez l'installation de WASSAFRICA.
  2. Dans Safari sur les versions compatibles, utilisez Fichier → Ajouter au Dock.
  3. Suivez la confirmation affichée.

Linux et ChromeOS

  1. Ouvrez WASSAFRICA dans Chrome ou Chromium compatible.
  2. Ouvrez le menu du navigateur.
  3. Choisissez « Installer la page comme application » ou l'option équivalente.

Si votre navigateur ne propose pas l'installation, ajoutez WASSAFRICA aux favoris.

Autres navigateurs

Si votre navigateur ne propose pas l'installation d'applications web, vous pouvez quand même utiliser WASSAFRICA directement dans ce navigateur ou l'ajouter aux favoris.

Utilisation hors connexion

Après une première ouverture avec Internet, WASSAFRICA peut retrouver certaines pages et ressources déjà mises en cache. Les données disponibles hors connexion dépendent des pages déjà chargées et du stockage conservé par votre appareil.

La connexion au compte, les nouveaux contenus du serveur, la synchronisation, les appels en direct et les paiements nécessitent Internet. Une action en attente n'est pas une commande payée : aucun paiement n'est confirmé hors connexion.

Conseil : ouvrez WASSAFRICA une première fois avec une bonne connexion, puis vérifiez les pages dont vous avez besoin avant de partir hors ligne.
