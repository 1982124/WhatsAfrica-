# WASSAFRICA — UI/UX system

## Direction

**Calme, humain, africain, lisible, utile.**

La page doit expliquer rapidement ce qu’on peut faire puis rendre le prochain geste évident.

## Palette

- Vert forêt `#173B2A` — structure, confiance, surfaces fortes.
- Crème `#F7F4EC` — fond principal.
- Blanc `#FFFFFF` — cartes et zones de lecture.
- Or chaud `#D9A441` — action principale et petits repères.
- Texte `#18201B` — lecture.
- Gris `#69746E` — texte secondaire.

### Règle

Le vert et le crème portent l’identité. L’or est un **accent**, pas une seconde palette. Pas de bleu électrique, violet, rouge ou dégradés multicolores pour décorer.

## Hiérarchie

1. Une phrase qui explique la valeur.
2. Une action principale.
3. Une action secondaire si nécessaire.
4. Une illustration qui explique, pas une illustration qui occupe l’espace.
5. Les détails seulement après l’action.

## Smart Link

Ordre recommandé :

1. identité / activité ;
2. ce qui est proposé ;
3. **Parler** ;
4. audio / vidéo ;
5. produits et services ;
6. partager / recommander.

Le visiteur ne doit pas avoir à comprendre le produit WASSAFRICA avant de comprendre l’activité qu’il consulte.

## Appels

Le parcours doit dire simplement :

> Commencez dans une conversation. Quand vous voulez parler, lancez l’audio ou la vidéo.

Aucun bouton WhatsApp ne doit être présenté comme une étape nécessaire du parcours WASSAFRICA.

## Illustrations

Une illustration est justifiée si elle réduit le temps de compréhension. Préférer des formes simples, monochromes ou bichromes, aux compositions très colorées.

## Mobile

- boutons tactiles d’au moins ~48 px de hauteur ;
- une colonne sur petit écran ;
- champs pleine largeur ;
- titres courts ;
- pas de contenu critique caché derrière un décor ;
- éviter les cartes imbriquées dans des cartes imbriquées.
