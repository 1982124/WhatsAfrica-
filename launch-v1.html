Les 3 certifications terrain

Ces tests font foi.

01 · Google OAuth

Un utilisateur réel doit réussir connexion → session → profil → déconnexion → reconnexion.

  1. Ouvrir Auth.
  2. Choisir Google.
  3. Autoriser.
  4. Vérifier session et profil.
  5. Se déconnecter puis revenir.
Ouvrir le test →

02 · E2EE A ↔ B

Deux comptes distincts doivent échanger des messages réellement chiffrés et déchiffrables après reconnexion.

  1. Créer A et B.
  2. A → B puis B → A.
  3. Recharger les deux clients.
  4. Fermer/réouvrir.
  5. Contrôler l'absence de plaintext en base.
Ouvrir la messagerie →

03 · SMS OTP

Un vrai téléphone doit recevoir l'OTP et permettre la création/récupération de session.

  1. Ouvrir Auth.
  2. Saisir un numéro réel.
  3. Demander OTP.
  4. Recevoir le SMS.
  5. Vérifier le code puis recommencer.
Ouvrir le test →
Règle CTO : « configuré » ≠ « fonctionnel » ≠ « certifié » ≠ « succès ». Une certification terrain manquante reste jaune. Une métrique sans utilisateur réel et sans contexte n'est pas une preuve de traction.
