# WASSAFRICA — Product brief

## Promesse

**WASSAFRICA = l’endroit où la découverte devient conversation, la conversation devient affaire, l’affaire devient relation, et la relation devient recommandation.**

## Principe CTO

WASSAFRICA ne doit pas avoir plus de fonctionnalités que les autres. Il doit avoir **moins de friction** pour arriver au résultat.

### Parcours central

**VOIR → COMPRENDRE → PARLER → FAIRE AFFAIRE → REVENIR**

## Pour les personnes

- retrouver et contacter des personnes ;
- échanger dans la messagerie ;
- rejoindre des communautés ;
- découvrir des activités, produits et services ;
- appeler en audio ou vidéo depuis le parcours WASSAFRICA ;
- garder le contact et partager le bon lien.

## Pour les activités

- présenter une identité claire ;
- disposer d’un Smart Link ;
- montrer produits et services ;
- recevoir une conversation directe ;
- faire avancer une demande, une négociation ou une vente ;
- rester recommandable via un lien unique.

## Smart Link

Le Smart Link doit être plus qu’une URL : c’est la représentation opérationnelle d’une activité.

**Présenter → découvrir → comprendre → parler → négocier → acheter/payer → rester en contact → recommander.**

## Ligne visuelle

- base : vert forêt + crème + blanc ;
- accent : or chaud, utilisé avec parcimonie ;
- aucune palette multicolore par fonctionnalité ;
- illustrations simples et utiles ;
- une action principale clairement dominante ;
- mobile-first ;
- texte court, action visible ;
- éviter les badges, gradients et effets décoratifs sans valeur fonctionnelle.

## Afrique d’abord

Les parcours doivent rester utilisables avec une connexion mobile ordinaire, sur petits écrans, et avec des étapes compréhensibles sans connaissance technique.
